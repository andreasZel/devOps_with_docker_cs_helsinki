
# EXERCISE 1.15: HOMEWORK

Link to docker image on docker-hub:

https://hub.docker.com/r/hoffmanntom/leaky


## Instructions

Fetch the container with:  
```bash
docker pull zelhs/sortinghelsinki
```

To run the container, use:  
```bash
docker run -d --rm -p 8000:8000 zelhs/sortinghelsinki
```

You can now access the website via browser:
```bash  
http://localhost:8000
```
